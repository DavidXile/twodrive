# Windows 只读文件夹挂载

2026-10-28 本地预览实现；尚未部署到用户正在运行的客户端。本机 WinFsp 未安装，真实 Windows 文件系统及 iCloud 挂载尚待验证。

## 使用

安装 [WinFsp 官方运行组件](https://winfsp.dev/rel/) 后，在 TwoDrive 选择已登录网盘，点击顶部“挂载”，或进入“设置 → 文件管理器挂载”。完成后可以在资源管理器中打开对应文件夹。挂载目标默认使用原连接的 `mount_path`；高级设置可修改为本机磁盘上尚不存在的子文件夹。已有文件夹、文件、账号或私有缓存目录不会被覆盖。这里实现的是文件夹挂载，不是 CFAPI 占位文件或离线同步。

挂载内可浏览、打开、复制文件，写入、删除、改名等操作始终关闭，包括本身可写的 OneDrive 连接。iCloud 本身的写能力也保持关闭。首次读取某个文件会先流式下载到本机临时缓存并验证对象、元数据版本和大小，再提供随机读取；大文件首次打开可能需要等待和占用相应本地空间。不要把它描述成云端按字节范围下载或瞬间打开大文件。

选择另一个已连接网盘保留原挂载，可分别挂载多个连接。客户端会在断开、退出登录或退出时卸载自己的挂载。卸载或退出前应先完成资源管理器中的文件复制；原生应用的文件句柄/复制不是 GUI 下载任务，当前没有承诺跨应用复制事务或断点恢复。没有加入开机自动挂载。

## 边界与实现

- Flutter 只消费 `mount_support`、协商的 `capabilities.mount` 和绑定 `profile/revision` 的 mount/unmount IPC。未安装驱动时给出安装入口，不伪造已挂载。
- 受控 worker 校验保存的 session/revision/binding，再从注册边界恢复同一个 Provider。iCloud 的凭据和协议仍只在适配器内，Windows 组件不获得 Apple 密码、令牌或私有 Rclone 配置。
- 通用 `readonly_mount` 使用 Provider 的浅层列表、路径到不透明 ID 查询和流式下载。仅监听随机 loopback 端口，用随机 bearer 凭据；所有写方法在 HTTP 层拒绝，文件系统层同样无写接口。限制连接、请求头、请求体和目录深度，不开放整盘递归枚举。
- 下载临时文件只有在对象 ID、元数据版本、大小检查通过后加入内存索引；HTTP Range 使用独立本地文件游标，避免并发错位。保留至多八个版本 / 2 GiB 的缓存，单个更大的正在读取文件例外；活动读者持有自己的句柄。元数据指纹仍有原适配器的同 ID/大小/时间戳变化边界，不因此获得服务端强版本保证。
- 容量复用 Provider 的账号额度，通过 DAV quota 属性转发；成功缓存五分钟，失败或不支持时短暂退避，不以零冒充未知。官方组件检查包含真实 Rclone `about` 对合成额度的读取。提供者不返回容量时，资源管理器可能显示组件的默认估算值，应以客户端的容量状态为准。
- 官方 Rclone v1.75.2 只访问上述本机 WebDAV 接口，VFS ReadOnly 强制开启。RC 同样只监听 loopback，使用独立随机用户名、密码并核对子进程 PID；本机凭据只通过私有环境传递。任意组件错误正文和日志不进入公共 IPC。
- Windows Job 绑定所属 worker 和组件进程树，正常卸载使用已认证的 mount/unmount；取消或启动失败回收本次进程树。不会卸载其他程序的挂载。常规结束清理本次临时目录；异常终止可能遗留只读缓存，本轮不自动删除旧缓存。

Rclone 的 [Windows 挂载说明](https://rclone.org/commands/rclone_mount/#installing-on-windows) 和 [RC 接口](https://rclone.org/rc/) 为组件依据。WinFsp 安装涉及系统驱动及 Windows 的管理员确认，客户端不静默安装或绕过确认。
